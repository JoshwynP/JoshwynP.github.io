# Joshwyn Parekh Portfolio

## How to use

1. Extract this zip anywhere on your computer.
2. Open Windows Terminal in this folder.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to preview locally.
5. Switch to `gh-pages` branch: `git checkout -b gh-pages`.
6. Build & deploy: `npm run deploy`.
7. Push branch: `git push origin gh-pages`.
8. Site will be live at https://joshwynp.github.io/

## Customize

- Replace `logo.png` and `resume.pdf` in `src/assets/`.
- Copy React Bits Liquid Ether & Electric Border code into `src/components/`.
- Add your actual projects, links, and social handles.
